# ⚡ JavaScript Interactive Webpage

A beginner-friendly interactive webpage built using HTML, CSS, and JavaScript. The project demonstrates dynamic user interactions and core JavaScript concepts through engaging features such as color-changing buttons, time-based greetings, and a simple calculator.

## ✨ Features

- 🎨 Dynamic Button Color Changes
- ⏰ Time-Based Greetings
- 🧮 Simple Calculator
- ⚡ Interactive User Experience
- 🖱️ Event Handling
- 🔄 DOM Manipulation

## 🛠️ Tech Stack

- HTML5
- CSS3
- JavaScript

## 🎯 Learning Outcomes

- JavaScript Fundamentals
- DOM Manipulation
- Event Handling
- Interactive Web Development
